# ShiftSwap Scope

## In Scope (MVP)

- Employees can post a shift they need covered and view open shifts.
- A coworker can request to pick up an open shift.
- Managers can approve or deny each request before the swap is finalized.
- Employees can view the request status.
- The core workflow is usable in a web browser and demonstrated by the end of Sprint 1.

## Out of Scope (v1)

- **Third-party integrations** (for example, Slack or scheduling-platform connections): defer to keep the MVP self-contained and avoid integration setup and support work before the core workflow is validated.
- **Single sign-on (SSO):** defer to avoid coupling the first release to an organization's identity-provider configuration; use a simple, agreed MVP access approach instead.
- **Payroll and overtime integration or calculations:** defer because pay rules and labor policies add significant complexity and require HR/payroll validation beyond shift-request handling.

## Sprint 1 Goal

Employees can post and request to pick up open shifts, and managers can approve or deny each request before a swap is finalized.
